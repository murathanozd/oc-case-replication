## 4. Conclusion

- Def. 7: E_i^o is convex, so projecting an execution never changes the DF relation between its events (no extra, no missing edges).
- Def. 11: E_i^o|X̄ is convex only in df(D, O \ X), not in D. Recomputing DF on the projection then creates spurious edges across the dropped events, and the excluded objects' own DF edges come back. The filtered case, read as an OCED-set, does not have the behaviour that defined it.
